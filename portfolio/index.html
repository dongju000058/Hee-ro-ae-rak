01 / OVERVIEW

감정은 사라지는 것이 아니라,
움직임을 거쳐 흔적으로 남는다.

〈감정을 마주하다 — 희로애락〉은 감정을 설명하거나 평가하는 대신, 관람객이 직접 움직여 감정의 형태를 바꾸는 인터랙티브 웹 작품입니다.

카메라, 마우스, 키보드와 몸짓은 각 감정에 맞는 매체가 되고, 경험의 끝에는 사진·파편·문장·소리의 흔적이 남습니다.

TYPE
Interactive Web
ROLE
Concept · UX/UI · Development
MEDIA
Camera · Mouse · Keyboard · Gesture
OUTPUT
Photo · GIF · Print · Motion · Sound

02 / FOUR EMOTIONS

같은 화면 안에서,
감정마다 다른 움직임을 설계하다.

01
喜

기쁨을 포착하다

떠오른 기쁨을 표정과 움직임으로 기록합니다. 네 장의 사진을 고르고 꾸민 뒤, 사진·GIF·인쇄물로 남깁니다.

  • Webcam capture
  • Four-cut editor
  • Firebase QR sharing
02
怒

분노를 통과하다

작은 자극을 마주하고, 마음에 걸린 말을 꺼내 파일로 만든 뒤 반복적인 움직임으로 파쇄합니다.

  • Mouse interaction
  • Text fragmentation
  • Progressive release
03
哀

슬픔 곁에 머물다

마음에 머무는 문장을 꺼내 바라보고, 세 번의 호흡과 함께 문장이 천천히 옅어지는 과정을 경험합니다.

  • Text input
  • Guided breathing
  • Afterimage motion
04
樂

즐거움을 증폭하다

손과 몸의 움직임을 인식해 음악의 속도와 에너지를 바꿉니다. 관람객의 제스처가 곧 연주가 됩니다.

  • Gesture tracking
  • Audio tempo
  • Realtime waveform

03 / EXPERIENCE SYSTEM

감정을 호출하고,
변환하고, 흔적으로 남긴다.

  1. 01

    호출

    관람객이 현재 마주하고 싶은 감정을 선택하고 개인적인 기억이나 문장을 떠올립니다.

  2. 02

    변환

    카메라·마우스·키보드·몸짓을 통해 감정에 고유한 움직임을 수행합니다.

  3. 03

    흔적

    사진, GIF, 파편, 잔상과 소리로 변한 결과가 화면과 인쇄물에 남습니다.

04 / PHYSICAL TRACE

화면을 벗어나
손에 남는 경험.

‘희’에서 만든 네 컷은 QR로 휴대폰에 저장하고, 전시장에서는 4×6인치 엽서로 바로 인쇄할 수 있습니다. 디지털 인터랙션이 개인적인 기념물로 이어지도록 설계했습니다.

05 / IMPLEMENTATION

브라우저를
전시 장치로.

별도의 앱 설치 없이 웹 브라우저 하나로 네 가지 경험을 연결했습니다. 전시 환경에서는 일정 시간 입력이 없으면 인트로로 복귀하고, 카메라 스트림은 경험 종료 시 중지됩니다.
